适用范围：激励换手线（Arcus RWA 贴一档挂单 + Lighter RH 吃单对冲）和后续所有
需要把主观判断写成规则的研究。W08–W16 都是 `selection_dev`，不是未触碰
holdout。本文只含汇总数字，不含账户、订单或成交原始记录。详细推导保存在本地
研究目录 `.agent-state/research/ant_three_venue_20261120/FINDINGS_2026_11_21.md`
§8c–§8h（不进 Git）。

成本口径：$/M = −（按两场所中间价计的权益变化）/ Arcus maker 成交额 × 1e6。
对冲腿成交额另报。用户设定的目标是 $100 成本换 $50M 成交，即 **$2/M**。

## 1. 方法：判断写成规则，事后能查出哪一环错了

主观判断仍由人做：谁受到什么约束、机会可能在哪。系统负责记录当时看见了什么、
接下来应该发生什么、什么证据会推翻判断，以及当时的盘口能不能把交易做完。

**逐环检验（过程追踪）。** 一次事件拆成十个事实仍然只是一次事件。同一次冲击下的
逐笔成交、不同币和不同场所可以检查时间顺序、排除解释，但不能当作独立样本。小样本
估不出长期胜率，却足以推翻一条必要前提。每一环事前写两句话：

- 如果我的解释对，接下来会看到什么？
- 如果最强的竞争解释对，又会看到什么？

参考：Collier, *Understanding Process Tracing*, PS: Political Science & Politics,
[doi:10.1017/S1049096511001429](https://doi.org/10.1017/S1049096511001429)。

**事件卡。** 每条规则一张卡，在下一次观测之前冻结：

| 字段 | 内容 |
| --- | --- |
| 看到了什么 | 触发时可观察的量，按策略实际收到行情的时刻（`available_at_ms`）对齐 |
| 预期下一步 | 主解释成立时的可观察结果，以及最强竞争解释的可观察结果 |
| 推翻条件 | 哪个结果出现就判定主解释不成立 |
| 允许动作 | 只列动作（暂停某侧、撤单、恢复），不含方向押注 |
| 失效 | 到期时间、数据过期或缺失时的处理（默认撤回许可） |
| 记录 | 触发、接近但未触发、失败、缺数据，四类都要记 |

起草时用一个成功案例和一个当时也像、后来没走出来的案例。短事件检验机制，
[连续十小时单元](TEN_HOUR_RESEARCH.md#measurement-contract)检验策略在不断仓、
不重置预算的情况下能否承担执行摩擦并结清现金。

**产出。** 很多观察最有价值的产出是一个禁做条件、一条退出规则，或者一个被排除的
机制。第 5 节是目前的清单。

## 2. 已有的断点例子

前提：触发时显示能保本，走完整个退出流程也能保本。两次历史触发的整周期估值为
+0.0021 和 +0.0103，经过撤单屏障、行情等待和双腿 IOC，3.6–4.0 秒后实际周期现金为
