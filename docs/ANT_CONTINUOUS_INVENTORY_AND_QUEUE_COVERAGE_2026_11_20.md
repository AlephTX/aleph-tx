## 1. 实现与实际结论

[新研究钱包](../scripts/research_ant_inventory.py)在多轮报价之间保留库存、现金、费用、未决订单和损失预算；同侧成交不再机械地逐笔外部对冲，也不在每笔成交后强制清仓。已确认的模拟净敞口超过固定带才提出保护价对冲，最后分别清掉两所库存。

三个既有历史短窗最终为 **1 个微利结清、2 个未结清**。唯一正值只有一次约 $60 的 maker 卖出及之后的主动买回，**尚未观察到双边 maker 自然对消，三个窗口也均无外部净额对冲成交**。这轮完成了机制和失败状态的实现，不能据此声称连续库存已经验证盈利或巨量能力。

另一项实质发现是队列模型的覆盖边界：完整 20 档盘口的价格区间内，某个价位缺席表示该价位的**可见排队量为零**；越出观测深度才属于未知。初版把两类情况混在一起，造成两处不必要的终值未知。修正保持所有费用、仓位、延迟和停止参数不变，未放宽迟报、断连或账户终态要求。

## 2. 唯一研究配置与账本边界

配置在首次读取该候选结果之前登记；只在已消费的三个旧窗口做历史诊断。没有新前向或十小时盈利验证。

| 项目 | 固定研究值或行为 |
| --- | --- |
| 独立纸面资金 | Arcus、xyz 各 $1,000；不是用户实盘预算 |
| 报价 | Arcus 买一/卖一双边，各最多约 $100；不超过相应一档数量的 20% |
| 刷新与到达 | 每 15 秒决策；310 ms 到达；报价活跃源时间区间 3 秒，取消在决策后 3 秒发送、310 ms 后模拟生效 |
| 订单数量 | 共同 0.01 ANT 下单单位；共同研究最低名义额 $10 |
| 风险预留 | 单场所及最坏净敞口各 $500；买卖未决量分别计算上下界，不能互相抵销 |
| 净额对冲带 | 初始规则固定 $100，以当前可见参考价换算；超额才尝试 xyz IOC |
| 费用 | Arcus maker 0、taker 1.12 bp；xyz taker 条件情景 0.9 bp；激励 0 |
| 对冲与退出 | 决策盘口固定保护价，310 ms 后按可见深度计实际模拟部分量；不在到达时放宽限价 |
| 损失停止 | 决策及已知成交后以可见完整平仓估值检查 $10；缺估值保留，非逐时刻损失保证 |
| 终端 | 停止报价，分别尝试两场所保护价平仓；碎量、残仓、未知订单均不报最终现金 |

主要边界：

- 公开打印只提供**条件性排队分配模型**，不是我方实际成交。完整可见排队量优先消耗；价格区间内空档不代表没有隐藏流动性。
- 已知部分成交即时记量和费用；迟报或未确认后缀仍保留余量风险。订单步长不等于部分成交步长，不能把小于 0.01 ANT 的部分成交直接舍去。
- 模拟撤单/IOC 的终态回调只是研究假设。超时、空 open-orders、公开行情序列都不能授权释放真实账户预留；本模块没有任何交易 API。
- 已知成交身份重复不重复记账；同身份内容矛盾停止新开。reduce-only 不能穿零，也不能用两个待发平仓单重复消耗同一仓位。
- 若任何场所有仓位或未决订单跨越资金费整点，但缺准确的该场所支付证据，最终现金保持未知。两所净数量为零也不等于资金费为零。
- 所有仓位和净额上限均按决策参考价约束，不能保证价格跳变、执行延迟和数据缺口中不越界。未建模市场对手方反应、真实拒单或不同抵押品的转换损益。

## 4. 最终逐窗结果与完整周期归因

三个声明窗口均为独立 20 分钟历史片段，钱包遇到停止条件后不重启或重置。下表列实际停止时刻，不能把它们拼成连续十小时。

| CST 窗口 | 停止发生于窗内 | 已知 maker 额 | 最终状态 | 解释 |
| --- | ---: | ---: | --- | --- |
| 16:00–16:20 | 13 分 48.31 秒 | $59.73955 | **+$0.0492154312**，两所平仓、无未决量 | 对冲决策行情缺失触发停止；随后 Arcus 保护价买回成功 |
| 17:15–17:35 | 6 分 33.31 秒 | $99.44724 | **未结清：Arcus 多头 1.09 ANT** | 停止后的保护价卖单没有分配，不能当作成交平仓 |
| 18:10–18:30 | 18.31 秒 | $0 已知成交 | **未结清：卖单风险区间 −1.09 至 0 ANT** | 相关公开成交迟报，实际分配未知；已知仓位为零不代表空仓 |

16:00 的唯一结清周期拆账：

- 模拟 maker 卖出 0.65 ANT，价格 91.907，名义额 $59.73955。
- 从已知成交记账到平仓记账约 **120.31 秒**；随后按 91.821 买回，名义额 $59.68365。
- 价格变动贡献 **+$0.055900**，买回费用 **$0.0066845688**，净额 **+$0.0492154312**。
- 中间已观察到的最低平仓估值为 −$0.0294433776；缺失时段不能据此推断最大回撤。

这笔收入主要来自持有空头期间的有利价格移动；它没有证明双边被动价差循环，更没有验证大额净额对冲。三个钱包的 xyz 实际模拟成交量均为零；不能拿本轮微利外推每百万成本或市场容量。

独立合成全流程还验证了“先两笔 maker 买入、净额对冲、随后 maker 卖出、终端两腿排空”：看似赚到的 maker 价差被对冲往返价差抵消，最后费用使现金为 **−$0.02879712**。该用例只验证会计完整性，不是行情收益证据。
